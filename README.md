# Lux · 英雄联盟智能选人推荐插件

基于 [Pengu Loader](https://pengu.lol/) 的国服英雄联盟客户端插件。在**英雄选择阶段**根据双方已选/已 Ban 阵容，实时给出推荐英雄：英雄网格角标 + 侧边推荐面板。

- 数据源：[101.qq.com](https://101.qq.com)（腾讯官方，国服数据：位置胜率 / 对位 / 协同 / 强度梯度）
- 评分模型：协同 35% + 克制 35% + 版本强度 20% + 阵容平衡 10%
- 英雄元数据（名称 / 伤害类型 / 分路）运行时从客户端本地资源读取，新英雄自动支持

## 功能特性

| 功能 | 说明 |
|---|---|
| 推荐面板 | 选人阶段右侧自动出现；按你的分路给 Top 3 + 各位置速览 + 阵容分析 |
| 英雄网格角标 | 红色 = 强烈推荐，绿色 = 可选，灰色 = 不建议；悬停查看各维度分数 |
| 实时重算 | 双方每次选人 / Ban 人都会重新评分（防抖 500ms） |
| 国服数据 | 101.qq.com 实时数据（面板显示数据日期） |
| 优雅降级 | 接口不可用时显示「(本地数据)」，全中性评分，不影响客户端 |
| 范围限制 | 仅排位 / 匹配（400/420/430/440/480）；大乱斗等不启用 |

## 安装

### 前置条件

[Pengu Loader](https://pengu.lol/) 已安装（一次性；装好后状态显示 ready，之后不用再打开它）。

### 方式一：一键安装（推荐）

1. 从 [Releases](https://github.com/giao1907/lux/releases) 下载 `lux-v*.zip` 并**完整解压**
2. 双击 `install.cmd`，按提示完成（自动定位英雄联盟目录；找不到会弹窗让你手动选择）
3. 重启英雄联盟客户端，或在 Pengu Loader 窗口点击「刷新」

### 方式二：手动安装

打开 Pengu Loader 窗口 → 点击 **Plugins** 按钮打开插件目录 → 把 `lux` 文件夹整个拖进去（里面应有 `index.js` / `index.css`）→ 回到 loader 点「刷新」→ 重启客户端。

## 使用

1. 进入排位 / 匹配的选人阶段 → 右侧自动出现「Lux 推荐」面板
2. 面板：**推荐位**（你的分路 Top 3）、**各位置速览**、**阵容分析**（AP/AD 配比提示）
3. 角标：红色大角标 = 强烈推荐（总榜 Top 3）；绿色 = 可选；灰色 = 不建议；悬停看维度分解
4. **F3**：显示 / 隐藏面板；面板右上角 x 临时关闭
5. 首次进入选人需要 1~3 秒拉取数据（约 40 个请求，并发 5），面板稍晚出现属正常
6. 离开选人阶段，角标与面板自动清空

## 更新 / 卸载

- **更新**：下载新版本压缩包，解压后再次双击 `install.cmd` 覆盖即可（建议先关闭客户端）
- **卸载**：双击 `uninstall.cmd`，或手动删除插件目录中的 `lux` 文件夹

## 常见问题

| 现象 | 处理 |
|---|---|
| 双击 `install.cmd` 出现安全警告 | 选「仍要运行」（脚本均为明文，可自行查看内容） |
| 提示「未检测到 Pengu Loader」 | 先安装 Pengu Loader 再运行安装脚本 |
| 面板显示「(本地数据)」 | 101.qq.com 接口不可用（断网等），评分变为中性，不影响客户端 |
| 面板没出现 | 确认是排位/匹配、在选人阶段；确认插件目录已更新并重启客户端 |
| 排查日志 | 用 Pengu 的 DevTools 查看 Console 中 `[Lux]` 开头的日志 |

## 开发

```bash
npm install
npm run dev      # 开发模式：写入 Pengu 插件目录，代码热更新（需保持运行）
npm run test     # 单元测试（vitest）
npm run build    # 构建并复制到 Pengu 插件目录
npm run pack     # 构建 + 打包 release/lux-v*.zip（含一键安装脚本）
```

技术栈：TypeScript + React 19 + Vite 6 + Pengu Loader Runtime + LCU API。

主要模块：

```
src/
├── lib/
│   ├── qq101.ts            # 101.qq.com 数据源（解析器 + 请求客户端）
│   ├── positions.ts        # 位置映射（LCU / 内部 / QQ101 三层值域）
│   ├── champion-data.ts    # 英雄元数据运行时加载（名称/伤害类型/分路）
│   ├── candidates.ts       # 会话解析、候选筛选（纯函数）
│   ├── scorer.ts           # 多因子评分引擎
│   ├── lcu.ts              # LCU 连接（REST + WebSocket 事件）
│   └── features/champion-recommendation.ts  # 推荐功能编排
├── components/             # 推荐面板 + 网格角标（DOM 注入）
scripts/installer/          # 一键安装 / 卸载脚本（随 release 分发）
```

设计文档见 `docs/superpowers/specs/`，实现计划见 `docs/superpowers/plans/`。

## 数据来源与已知限制

- 对位 / 协同数据每个英雄仅覆盖最强 / 最弱各 5 个对位、Top 3 协同，未覆盖的组合按中性处理
- 匹配盲选无分配位置时，对位 / 协同不可用，仅按强度 + 平衡评分
- 匹配模式使用排位数据近似
